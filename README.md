# novel-memo
小说备忘录

一个单文件 PWA，用来记录读过的书：书名、作者、标签、评分、阅读时长与感想。数据存在浏览器本地，支持 JSON 备份导出/导入。

## 功能

- 分类筛选：顶部一行 全部 / 自定义分类 / 读完 / 在读 / 弃读，分类名可自己定义，点一下筛选、再点一下取消
- 快捷标签：编辑记录时，直接点选已经建好的分类即可加/减标签，不用手打
- 阅读状态：在读 / 读完 / 弃读，顶部实时统计
- 星级评分：1-5 星
- 主题封面：可建多套主题，每套配若干封面图，按顺序轮换；封面宽度/间距/圆角可调
- 配色主题：森绿 / 雾蓝 / 焦糖 / 樱粉 / 夜间
- 自定义字体：支持 ttf / otf / woff / woff2
- 时长显示格式：多种中文/英文格式可选
- 批量导入：一行一条 日期｜书名/作者【标记】
- 备份：一键导出 JSON、导入文件
